03 Lead Gen

Lead Generation System

leadgen.madebyrecipe.com
Connected

Powerful lead generation tool for building targeted prospect lists. Extract business contacts, verify emails, and export clean data for outreach campaigns.

Business Search Email Verification CSV Export Industry Filters
How to Use Lead Gen
1
Define Your Target Audience
Use the industry filters to narrow down your search. Select location, business type, company size, and other relevant criteria.
2
Run Search & Review Results
Execute your search and review the returned prospects. Each result includes business name, contact information, and verification status.
3
Verify & Clean Data
Use the built-in email verification to ensure deliverability. Remove invalid or risky addresses before export.
4
Export Your List
Download your cleaned lead list as CSV. Ready for import into your CRM or email marketing platform.
Best Practices for Lead Gen
  • Start narrow, then expand - Begin with specific criteria and broaden if you need more leads
  • Always verify emails - A 95%+ deliverability rate protects your sender reputation
  • Segment by industry - Create separate lists for different verticals
  • Regular cleanup - Re-verify lists older than 90 days before campaigns
  • Respect opt-outs - Maintain a master suppression list
Pro Tip
Combine Lead Gen with Email Builder for a complete outreach workflow. Generate leads, create personalized email campaigns, and track performance all within the Recipe Labs ecosystem.

Email Validator

Batch verify email lists before sending campaigns.

  • Syntax validation - Check for properly formatted addresses
  • MX record lookup - Verify domain accepts mail
  • Disposable domain detection - Flag temporary email services
  • Risk scoring - Rate deliverability likelihood
  • CSV upload/export - Handle bulk lists easily

Processing speed: ~1,000 emails per minute

Social Asset Resizer

One image → all social media sizes.

Supported platforms and dimensions:

  • Instagram - Feed (1080x1080), Story (1080x1920), Reel Cover
  • Facebook - Post (1200x630), Cover (820x312), Story
  • Twitter/X - Post (1200x675), Header (1500x500)
  • LinkedIn - Post (1200x627), Banner (1128x191)
  • YouTube - Thumbnail (1280x720), Banner (2560x1440)
  • TikTok - Cover (1080x1920)
  • Pinterest - Pin (1000x1500)

Export as individual files or bundled ZIP.

Metadata Stripper

Remove hidden data from images for privacy and file optimization.

  • GPS data removal - Strip location coordinates
  • Device info - Remove camera/phone identifiers
  • EXIF data - Clear all embedded metadata
  • File optimization - Reduce file size by 20-40%
  • Batch processing - Handle multiple files at once
Privacy Reminder
Always strip metadata from images before sharing publicly or with clients. Location data and device information can pose security risks.

  • Support for DOCX, RTF, and TXT formats
  • Clean HTML output (no Word cruft)
  • Preserves basic formatting (bold, italic, lists)
  • Email-client compatible code
  • Copy-paste ready output

Perfect for converting client-provided content into email templates.

09 Best Practices

Data Security Guidelines
  • Never share login credentials for Recipe Labs tools
  • Don't store client lead lists on unsecured devices
  • Always strip metadata from images before delivery
  • Use encrypted connections when accessing tools remotely
  • Log out of shared workstations after each session
Performance Optimization
  • Process lead lists in batches of 1,000 for optimal speed
  • Compress images before uploading to resizer (faster processing)
  • Export playbooks as PDF for client delivery (faster than live generation)
  • Use Chrome or Firefox for best tool compatibility
  • Clear browser cache monthly for optimal performance

10 Troubleshooting

Common Issues & Solutions

Tool not loading?

  • Clear browser cache and cookies
  • Try incognito/private browsing mode
  • Disable browser extensions temporarily
  • Check internet connection stability

Export not working?

  • Ensure pop-up blocker is disabled for our domains
  • Check available disk space
  • Try a different browser
  • Reduce batch size if processing large files

Email validation timing out?

  • Split large lists into smaller batches
  • Wait a few minutes and retry
  • Some domains may have rate limiting - normal behavior
